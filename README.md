# Second-Life-Resources
Repository of various files that are useful to users of Second Life.

## HDRI Files
HDRI files for use in your editor of choice, specifically tuned to be as close as 1:1 representation with Second Life's Midday preset (Note: not Midday Legacy!).

## Projector maker
Convert IES or LDT photometric files into a projector texture for use in Second Life. Also gives you the projection settings if you are trying to recreate the real lamp.

See here: https://quinn-elara.github.io/projector-cookie-generator/
